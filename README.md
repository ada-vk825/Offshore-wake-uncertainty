# Uncertainty-Aware Inter-Farm Wake Loss Prediction

This repository contains a machine learning framework for predicting offshore wind farm power and quantifying uncertainty in inter-farm wake losses.

The project uses physics-based wake simulations to generate training data and trains an XGBoost surrogate model to predict turbine-level power ratios from wind conditions, turbine specifications, neighbouring wind farm characteristics, and physics-informed geometric features.

The trained surrogate model is then used in Monte Carlo simulations to estimate the uncertainty in wind farm power and wake losses caused by uncertain neighbouring wind farm layouts.

## Project Overview

As offshore wind deployment increases, wind farms are increasingly affected by wakes generated by neighbouring wind farms.

Future neighbouring developments may have uncertain turbine layouts, spacing, turbine specifications, and locations. Running a physics-based wake model repeatedly for large numbers of possible layouts can become computationally expensive.

This project therefore uses a machine learning surrogate model to approximate the wake-model predictions and enable faster uncertainty analysis.

The overall workflow is:

1. Define target wind farm and neighbouring wind farm configurations.
2. Generate synthetic turbine layouts.
3. Define wind speed, wind direction and turbulence intensity scenarios.
4. Compute physics-informed geometric wake features.
5. Generate turbine-level power data using PyWake.
6. Train an XGBoost surrogate model to predict turbine power ratio.
7. Use the trained surrogate model for power prediction.
8. Perform Monte Carlo simulations with uncertain neighbouring layouts.
9. Estimate inter-farm wake loss and associated uncertainty.

The main modelling components are:

- PyWake physics-based wake modelling
- physics-informed geometric feature engineering
- XGBoost surrogate modelling
- Monte Carlo uncertainty quantification

The aim is to provide a reusable and computationally efficient workflow for uncertainty-aware offshore wind farm wake-loss prediction.

## Methodology

The project combines physics-based modelling and machine learning.

The training workflow can be represented as:

```text
Wind farm configuration
        ↓
Target and neighbour turbine layouts
        ↓
Wind conditions
        ↓
Physics-informed geometric features
        ↓
PyWake simulation
        ↓
Turbine power and power ratio
        ↓
XGBoost surrogate model
```

Once trained, the surrogate model replaces repeated PyWake simulations during prediction and uncertainty analysis:

```text
Target farm configuration
        +
Neighbour farm configuration
        +
Wind conditions
        ↓
Generate turbine layouts
        ↓
Physics-informed geometric features
        ↓
XGBoost surrogate model
        ↓
Turbine power ratios
        ↓
Turbine power
        ↓
Farm-level power
        ↓
Wake loss and uncertainty
```

## Physics-Informed Features

The surrogate model uses both physical wind farm parameters and geometric wake-interaction features.

The model inputs include:

### Wind conditions

- free-stream wind speed
- wind direction
- turbulence intensity

### Target wind farm characteristics

- rotor diameter
- hub height
- rated power

### Neighbour wind farm characteristics

- distance from the target farm
- direction relative to the target farm
- number of turbines
- turbine spacing
- rotor diameter
- hub height
- rated power

### Physics-informed geometric features

For each target turbine, geometric relationships with surrounding turbines are calculated.

These include:

- number of blocking turbines
- blocking ratio
- blocking distance
- streamwise distance to the first blocking turbine
- lateral distance to the first blocking turbine
- rotor diameter of the first blocking turbine

The physics-informed features provide information about the wake exposure of individual target turbines.

## Target Variable

The machine learning model predicts turbine-level power ratio:

```text
power_ratio = turbine_power / rated_power
```

The predicted power ratio is converted back to turbine power:

```text
predicted_power = predicted_power_ratio × rated_power
```

The individual turbine powers are then summed to obtain total wind farm power.

## XGBoost Surrogate Model

XGBoost is used as the surrogate regression model.

The model learns the relationship between:

```text
Wind conditions
+
Turbine specifications
+
Neighbour farm configuration
+
Physics-informed geometric features
        ↓
Turbine power ratio
```

The trained model is stored as:

```text
best_model.pkl
```

This is the default model used for subsequent predictions and Monte Carlo uncertainty simulations.

The model pipeline handles missing feature values using median imputation before prediction.

## Monte Carlo Uncertainty Analysis

Monte Carlo simulation is used to quantify uncertainty caused by uncertain neighbouring wind farm layouts.

For a given target and neighbour configuration:

1. The target wind farm layout is generated.
2. The target layout remains fixed during the Monte Carlo simulation.
3. A neighbouring wind farm configuration is defined.
4. Neighbour turbine spacing is sampled from the specified spacing values.
5. A neighbouring farm polygon is generated.
6. Turbines are randomly positioned within the neighbouring farm.
7. Physics-informed features are calculated for each target turbine.
8. XGBoost predicts the power ratio of each target turbine.
9. Power ratios are converted to turbine power.
10. Turbine powers are summed to obtain total target-farm power.
11. Wake loss is calculated.
12. The process is repeated across the Monte Carlo samples.

The default number of Monte Carlo simulations is:

```text
50
```

The final uncertainty result is reported in a compact form such as:

```text
Wake loss: 12.0 ± 3.0 %
```

and the corresponding power loss can be reported as:

```text
Power loss: 4.5 ± 1.1 MW
```

where the uncertainty represents the standard deviation across the Monte Carlo simulations.

## Synthetic Wind Farm Layouts

When an existing wind farm polygon is not provided, synthetic square wind farm polygons can be generated from:

- number of turbines
- turbine spacing
- rotor diameter

The approximate farm dimensions are determined from the number of turbines that can be arranged along each side of the square.

Neighbour wind farms are positioned relative to the target wind farm using:

- neighbour distance
- neighbour direction

Turbines are then randomly positioned inside the generated polygon while respecting the specified minimum turbine spacing.

## Existing Wind Farm Polygons

The uncertainty workflow can operate without an existing wind farm polygon.

By default, a synthetic target wind farm is generated from the supplied target turbine specifications.

Where required, an existing target wind farm can instead be selected from the wind farm geospatial dataset:

```text
gdf.gpkg
```

This allows the same uncertainty framework to be applied to real wind farm boundaries.

An example Monte Carlo simulation can be run using:

```bash
python main.py monte-carlo \
  --target-turbines 44 \
  --target-diameter 164 \
  --target-hub-height 105 \
  --target-rated-power 8400 \
  --target-spacing 5 \
  --nb-distance 15 \
  --nb-direction 270 \
  --nb-turbines 60 \
  --nb-spacing-values 3 5 7 9 \
  --nb-diameter 178 \
  --nb-hub-height 119 \
  --nb-rated-power 10000 \
  --wind-speed 10 \
  --wind-direction 270 \
  --ti 0.06
```

The trained model is loaded automatically from the default model location.

The simulation returns the estimated wake loss and uncertainty rather than storing every Monte Carlo sample.

## Model Training

Training data contain turbine-level observations generated from physics-based wake simulations.

The model uses the features defined in:

```text
src/wake_uncertainty/config.py
```

and predicts:

```text
power_ratio
```

The training workflow includes:

- feature validation
- missing-value handling
- train/test splitting
- XGBoost training
- model evaluation
- model persistence

Typical regression metrics include:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- coefficient of determination (R²)

The best trained model is saved as:

```text
best_model.pkl
```

## Data Generation

Training data are generated from combinations of:

- target wind farm configurations
- neighbour distance
- neighbour direction
- neighbour turbine count
- neighbour turbine spacing
- turbine specifications
- wind speed
- wind direction
- turbulence intensity

For every target turbine, physics-informed geometric features are derived before the physics-based power result is added to the training dataset.

The generated data contain turbine-level power and power-ratio targets for surrogate-model training.

## Wind Data

Wind conditions can be derived from ERA5 data.

The workflow supports quantities including:

- wind speed
- wind direction
- Weibull parameters
- directional sector frequencies

Wind speed can be calculated from horizontal wind components as:

```text
ws = sqrt(u² + v²)
```

Wind direction is converted into meteorological convention before being used in wake simulations and feature calculations.

## Evaluation

The surrogate model is evaluated by comparing predicted and reference turbine power ratios.

The main evaluation metrics are:

- MAE
- RMSE
- R²

Sensitivity analysis can additionally be used to examine whether predicted wake behaviour follows physically sensible trends with changes in:

- neighbour distance
- wind direction
- wind speed
- turbine spacing
- turbulence intensity
- neighbouring wind farm size

## Streamlit Web Application

The project includes a Streamlit web application that provides an interactive interface for estimating inter-farm wake losses and their uncertainty using the trained machine-learning surrogate model.

The application allows users to define a target wind farm and neighbouring wind-farm conditions without directly interacting with the Python package.

### Existing Wind Farm

The user can select an existing offshore wind farm.

The application loads the corresponding wind-farm boundary from the available geospatial dataset and uses the real boundary as the target-farm polygon.

The user can then provide the target turbine information and neighbouring wind-farm specifications required for the prediction.

### New Wind Farm

The user can also define a new target wind farm.

The user provides the target turbine specifications, including:

- number of turbines
- turbine spacing
- rotor diameter
- hub height
- rated power

The application creates a square target-farm polygon based on these specifications.

The user then provides the neighbouring wind-farm specifications.

### Neighbouring Wind-Farm Inputs

The application allows the user to specify information such as:

- distance from the target farm
- direction relative to the target farm
- number of neighbouring turbines
- possible turbine spacings
- rotor diameter
- hub height
- rated power

Wind conditions required by the surrogate model are also provided through the application.

The Streamlit application passes these inputs to the uncertainty-analysis workflow, which uses the trained XGBoost surrogate model and Monte Carlo simulation.

The main outputs include:

- estimated mean wake loss (%)
- wake-loss uncertainty
- estimated mean power loss (MW)
- power-loss uncertainty (MW)
